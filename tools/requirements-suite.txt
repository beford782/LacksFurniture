# Python dependencies of the local CI mirror (tools/run_full_suite.ps1) and of
# the CI `verify` job, pinned in ONE place. CI installs exactly this file on
# Python 3.12. The mirror admits an interpreter only after
# tools/suite_python_preflight.py passes on it: every distribution this file
# resolves to for that Python is installed at exactly the pinned version and
# imports, and a headless Chromium actually launches through its Playwright.
#
# Supported interpreters: Python 3.12 through 3.14 (3.12 is CI's interpreter;
# 3.14 is the newest the pins are verified on). The preflight refuses an older
# OR a newer Python before any suite runs: no pin here is verified for 3.15+,
# so the Pillow markers below are closed at 3.14 rather than open-ended.
# Supporting a newer Python means pinning and verifying its requirements here
# and raising PYTHON_CEILING in tools/suite_python_preflight.py in the same
# change (tests/suite_preflight_check.py pins both). The commands are the same
# on every supported version; the markers choose the Pillow build. Provision
# the interpreter the mirror will use once:
#
#   <python> -m pip install -r tools/requirements-suite.txt
#   <python> -m playwright install chromium     (the browser the rendered check drives)
#
# openpyxl: workbook build/read. Pillow: image normalisation in the converter and
# the golden image compare. qrcode: the financing QR generator and the QR suite
# (pinned by incoming/requirements-qr.txt, referenced here so the pin has one
# home). playwright: the rendered layout check (tests/sleep_plan_layout_check.py).
#
# Pillow 11.0.0, CI's pin, publishes no wheels for Python 3.14, so 3.14 resolves
# to 12.1.1: the release the local mirror was verified with on 2026-09-06. Both
# pins are exact and the preflight refuses any other installed version, so the
# mirror on 3.14 differs from CI in that one distribution and nowhere else.
openpyxl==3.1.5
Pillow==11.0.0; python_version < "3.14"
Pillow==12.1.1; python_version == "3.14"
-r ../incoming/requirements-qr.txt
playwright==1.62.0
